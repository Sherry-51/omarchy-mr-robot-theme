## [1.0.0] - 2026-10-30

### Initial Release: MR. ROBOT — FSOCIETY WORKSTATION
- **System Palette (`colors.toml`):**
  - Engineered cold charcoal and graphite surface hierarchy (`#080A08`, `#050605`, `#030403`, `#171B17`).
  - Terminal phosphor muted green accent (`#83B566`) with bright indicator variant (`#A6D486`).
  - Restrained warning red (`#B94A4A`) and bright alert variant (`#E06B66`).
  - High-contrast, WCAG AAA compliant primary text (`#D5D9D2`) and muted secondary typography (`#899087`, `#62695F`).
  - Forest green selection background (`#243326`) with light foreground (`#EEF2EA`).
  - Hyprland border gradients (`rgba(83b566ee) rgba(355b36ee) 45deg`).
- **Application Integrations:**
  - **Neovim:** Seamless integration with Omarchy 4's native `aether.nvim` engine, delivering complete syntax highlighting across C, x86-64 assembly, Rust, Python, Lua, Bash/Zsh, Treesitter, and LSP diagnostics.
  - **Alacritty:** Full 16-color ANSI mapping with crisp contrast, muted green cursor, and non-distracting visual hierarchy.
  - **btop:** Dedicated cybersecurity monitoring dashboard (`btop.theme`) with custom gradient curves, green/cyan graphs, and red alert thresholds.
  - **Hyprland & Quickshell:** Native window border styling, top bar, application launcher, notifications, and lock screen integration.
  - **Browsers:** Dark theme hex integration (`chromium.theme`) for Chromium, Brave, and Edge.
  - **Icons:** Configured `Yaru-prussiangreen-dark` for dark surfaces and green folder accents.
  - **Plymouth / Unlock:** Created custom `unlock.png` and `preview-unlock.png`.
- **Wallpapers:**
  - Curated collection of 8 high-resolution 16:9 wallpapers (4K UHD, QHD, FHD) covering cinematic, minimalist, Elliot character portrait, CRT phosphor terminal, urban isolation, and abstract hacker styles.
  - Full source attribution and license documentation in `SOURCES.md`.
